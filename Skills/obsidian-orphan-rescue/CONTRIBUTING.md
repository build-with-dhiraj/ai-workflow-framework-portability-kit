# Contributing

`obsidian-orphan-rescue` is developed in the [Obsidian PKM Skills](../../) monorepo. The contribution process is shared across all three skills.

**See the root [CONTRIBUTING.md](../../CONTRIBUTING.md)** for development setup, the test/lint workflow, issue filing, style rules, and releases.

Orphan-rescuer-specific guidance — the high bar for a new mode and the low bar for a new safety guard — is in the [Proposing skill-specific changes](../../CONTRIBUTING.md#obsidian-orphan-rescue--new-modes-and-safety-guards) section there. The trust model is "every guard ships with a test that locks it in"; please label data-safety issues `safety` (see [SECURITY.md](../../SECURITY.md)).
